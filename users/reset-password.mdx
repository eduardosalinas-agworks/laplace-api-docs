# Redefinir senha

## Endpoint

```http
POST /sendmail
```

## Body

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `emails` | array[string] | Sim | Lista de e-mails dos usuários |

## Exemplo

```json
{
  "emails": [
    "usuario@escola.com.br"
  ]
}
```

## Resposta de sucesso

```json
{
  "messages": [
    "E-mail usuario@escola.com.br enviado(s) com sucesso."
  ]
}
```

<Note>
A resposta pode conter mensagens individuais indicando sucesso, usuário inativo ou falha por e-mail.
</Note>
