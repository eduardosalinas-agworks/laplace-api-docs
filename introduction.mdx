# API Banco Laplace

A API Banco Laplace permite a integração com recursos acadêmicos e administrativos, incluindo escolas, turmas, professores, alunos, usuários e catálogos auxiliares.

## URL base

```http
https://api.uat.laplace.app.br/api/v1/association/
```

<Info>
Esta documentação usa o ambiente UAT como referência. Para produção, confirme a URL base fornecida pela equipe Laplace.
</Info>

## Recursos disponíveis

| Recurso | Endpoint base | Descrição |
| --- | --- | --- |
| Escolas | `/schools` | Cadastro e manutenção de escolas |
| Turmas | `/classes` | Cadastro e manutenção de turmas |
| Professores | `/teachers` | Cadastro e manutenção de professores |
| Alunos | `/students` | Cadastro e manutenção de alunos |
| Usuários | `/sendmail` | Redefinição de senha por e-mail |
| Ensino | `/teachings` | Modalidades de ensino |
| Períodos | `/periods` | Períodos disponíveis |
| Séries | `/series` | Séries disponíveis |
